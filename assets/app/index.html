        How to use shacl-report

        Check RDF data against SHACL shapes, or read the report of any validator, and find out what is wrong and where. Open a topic below.

        Getting started
        • Validate data: drop your shapes and your data on the start screen and press Validate. shacl-report checks SHACL Core and SPARQL constraints itself.
        • Open a report: read the report of another validator (pyshacl, Apache Jena, TopBraid, RDF4J…). Add the shapes it used to name every shape and see the broken rule, and the data to see the resource behind each problem.
        • Shapes on their own open the Shapes explorer, without results.
        • No files at hand? Pick one of the demos under the form.
        • Open report, in the top bar, loads other files. Turtle, N-Triples, RDF/XML, TriG and N-Quads are read, also gzipped.
        • The Results tab starts with an overview: whether the data conforms, the number of results per severity, and the most affected shapes and most common problems. Click a bar to filter on it.
        Results and filters
        • Filter by severity, problem type and shape in the side panel (the filter button on a phone). Active filters show as chips above the results; click a chip's × to remove it.
        • The search box matches resources, paths, values and messages. Press / to jump to it.
        • Group by shape, resource or problem, or not at all, and switch between cards and a sortable table.
        Result details
        • Click a result to open it: the problem in plain words, the resource, path and value, and the rule it broke, such as sh:maxInclusive 150.
        • With the data loaded, Resource data lists the resource's triples and highlights the offending value, or says the value is missing.
        • Show only these lists every problem of the same resource.
        • j / k (or ↓ / ↑) go to the next or previous result, Esc closes the panel.
        Shapes
        • The Shapes tab lists every node and property shape. Each one says which resources it applies to, its rules in plain language, and how many results it produced; click the count to see them.
        • From a result, Explore this shape jumps to its shape.
        • The play buttons open a rule, a whole shape or its focus nodes as a SPARQL query, ready to run against your own triple store.
        SPARQL and exploring IRIs
        • In the SPARQL tab, enter the endpoint that holds your data and press Use endpoint. Run the queries from the Shapes tab, or write your own.
        • Relay through shacl-report sends the queries through this server, for endpoints that do not allow requests from the browser (CORS).
        • Ctrl+click (⌘+click on a Mac) any IRI to load its triples from the endpoint; Ctrl+Shift+click loads the triples that point to it. In that viewer, Ctrl+click again to keep exploring.
        Export and sharing
        • Export downloads the results you see as CSV, the whole report as one standalone HTML file that opens without a server, or the validation report as Turtle when shacl-report validated the data.
        • The same viewer is available from the command line, for example to publish an HTML report from a CI pipeline: see the README.
        • The theme button switches between light and dark.
